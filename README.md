# 🌌 Solar-System-Explorer-ThreeJS-Project

An interactive **3D Solar System Explorer** built with **Three.js**, allowing users to freely navigate the solar system, inspect each planet, and learn fascinating astronomical facts through a clean and cinematic interface.

![JavaScript](https://img.shields.io/badge/JavaScript-ES6-yellow)
![Three.js](https://img.shields.io/badge/Three.js-3D-black)
![Status](https://img.shields.io/badge/Status-Completed-success)

---

## 🚀 Features

- 🌞 Interactive 3D solar system built with **Three.js**
- 🪐 Eight orbiting planets with animated motion
- 🔍 Click any planet to smoothly zoom in and inspect it
- 📖 Informative side panel containing interesting facts about each planet
- 🎥 Smooth cinematic camera transitions
- ⭐ Dynamic starfield background
- 🎛 Adjustable orbit speed
- 🖱 Mouse drag to rotate the view
- 🔎 Mouse wheel zoom support
- 📱 Responsive layout for different screen sizes

## 💡 Why I Built This

This project was created to explore the fundamentals of **Three.js** and interactive 3D graphics while improving my front-end development skills.

Instead of building a simple solar system animation, I wanted to create a small educational experience with smooth camera movement, interactive navigation, and a clean user interface that feels immersive and enjoyable to explore.
